# 云序（OpenListPlayer）主流音频播放器 UI 调研与整体优化方案

> 版本：v2.0 设计蓝图（2026-11-25）  
> 适用范围：云序（OpenListPlayer）Android / iOS 全端 UI、App Logo 品牌识别、微交互动画与播放器高频体验闭环  
> 配套原型：[`docs/ui-prototype.html`](./ui-prototype.html)（浏览器直接打开，含新旧 Logo 对比、深浅色切换与可点击/可拖动的页面原型）

## 一、项目现状诊断与核心矛盾

### 1.1 云序的独特产品基因
与市面上依赖 ID3 标签扫描的本地音乐播放器或中心化流媒体 App 不同，「云序」是 **OpenList（挂载天翼云盘等云存储）的移动前端播放器**，其真实使用场景有四个鲜明特征：
1. **长音频与音乐双修**：既有几百集连载有声书、相声评书、播客录音、网课，也有整目录无损 `FLAC / MP3` 音乐与剧集视频；
2. **弱元数据、强目录结构**：网盘音频 90% 以上没有内嵌专辑封面或标准歌手标签，信息载体主要是**目录路径**与**带集数编号的长文件名**；
3. **重度依赖断点续播与排序**：用户按文件夹或自建播单追更，极度依赖自然排序（`2 < 10 < 100`）、精确到秒的独立续播以及弱网重连不回片头；
4. **渲染管线约束**：因部分 Android 16 / HyperOS 机型视频硬解兼容问题，`AndroidManifest.xml` 已关闭 Impeller（`EnableImpeller=false`），UI 动效必须避免高开销实时高斯模糊（`BackdropFilter` 大面积叠加），坚持纯 `Transform` / `Opacity` / 轻量 `CustomPainter` 的 120fps GPU 友好路线。

### 1.2 当前版本（v1.0）的五大体验痛点
1. **视觉割裂严重**：「音频页 `AudioPage`」与「底部 `MiniPlayerBar`」已采用极具质感的暖陶米白设计稿（Ardot 风格），但 `首页`、`文件`、`播单`、`设置` 四个主 Tab 仍停留在原生 Material 默认平铺 `ListTile` 阶段，进出播放页仿佛切换了两个 App。
2. **首页职能空心化且与播单页重复**：当前首页仅有一张「继续播放」卡片（一旦开始播放就会消失！）加上完整复刻第 3 个 Tab 的播单列表；而数据库层早已完备实现的 `historyStream`（最近播放 20 条记录）在 UI 上完全没有入口。
3. **文件浏览器缺乏「追更感知」与检索手段**：本地 `playProgresses` 表记录了每个网盘文件的播放进度，但文件列表页完全未展示——面对 150 集有声书，用户看不出哪集听完了、哪集听到一半，也没有目录内快速过滤框。
4. **`AudioPage` 长滚动误触与长音频控件缺失**：当前 `AudioPage` 为整页上下长滚动，单手拖进度条易误触页面滚动，200 集长队列翻找费力；主控区仅有三键（缺少听书刚需的 `±15s` 微调步进、睡眠定时、0.1x 精细倍速与同目录 `.lrc` 歌词展示），无封面时的静态 PNG 占位图也偏呆板。
5. **深色模式未激活 & 初代 Logo 细节零碎**：`app_theme.dart` 虽预置了 `AppPalette` 暗色色板，但 `app.dart` 硬编码锁死 `ThemeMode.light`，夜间睡前听书刺眼；初代 `yunxu_logo.svg` 用三个正圆硬拼云朵 + 尖锐直角三角 + 底部细碎短线，在小尺寸桌面图标下重心偏散、缺乏圆润现代感。

## 二、市场主流音频播放器 UI 深度调研拆解

围绕「长音频 + 音乐双修 + 私有云目录」三角定位，横向拆解三大赛道 7 款标杆产品的核心设计得失：

| 赛道类别 | 代表产品 | 值得云序吸收的核心 UI / 交互精华 | 云序需规避的不水土不服设计 |
|---|---|---|---|
| **播客与有声书赛道** | **小宇宙**、**Castro**、**Pocket Casts**、**Apple Podcasts** | 1. **人文纸感暖调（小宇宙）**：脱离千篇一律的纯黑霓虹，用温润浅底 + 高识别度品牌色营造耐看陪伴感；<br>2. **对称/近场步进盲操（`±15s`）**：紧贴中央大播放键布置快退/快进，单手拇指无需大幅移动；<br>3. **列表级进度透出**：每一集列表项直接显示细进度条或「已播完 / 剩余 xx 分钟」状态；<br>4. **睡眠定时与精细倍速**：底栏一键开启 15/30/60m 或「播完本集停」，倍速支持 `0.1x` 微调。 | 播客社交评论流、复杂订阅发现页与剧集 ShowNotes 富文本流，对网盘纯播放器属于噪音。 |
| **本地与无损音乐赛道** | **Apple Music**、**椒盐音乐 (Salt Player)** | 1. **一屏锁定构图 + 自底向上模态转场**：全屏播放器绝不上下长滚，支持下拉手势跟手缩放回落至 `MiniPlayerBar`；<br>2. **按压进度条增粗反馈**：平时纤细克制（`4pt`），手指按住瞬间平滑增粗至 `8pt` 并放大时间读数；<br>3. **封面与居中滚动歌词原位切换**：点击封面区即可用渐隐动效切换 `.lrc` 高亮滚动歌词，底部主控区稳如磐石；<br>4. **底部抽屉式队列**：点击队列角标弹出半屏圆角抽屉并自动定位到当前曲目。 | 强依赖专辑封面大图流体模糊背景（`BackdropFilter` 高斯模糊在无封面网盘音频与关闭 Impeller 的机型上既空洞又耗性能）。 |
| **私有云 / NAS 媒体赛道** | **Infuse**、**Plexamp**、**VidHub** | 1. **格式与音质徽章（Plexamp）**：从扩展名提取 `FLAC` / `AAC` / `MP3` / `MKV` 胶囊徽章，零元数据成本建立专业感；<br>2. **面包屑与目录快速筛选**：深层网盘路径用胶囊面包屑清晰导航，支持当前目录即时过滤；<br>3. **首页「继续观看/收听」英雄卡**：把最近中断的媒体放在视觉第一落点。 | 影视海报墙刮削（TMDB 元数据匹配对天翼云盘个人杂乱目录误配率高，违背云序轻量定位）。 |

## 三、品牌重塑：全新「云序」App Logo 与设计系统规范

### 3.1 全新 App Logo 设计：主流极简几何（4 套可切换提案，主推「声环留声」）
- **复盘与转向**：之前的具象云朵路线之所以始终显得笨重，是因为把「云朵 + 播放三角 + 三条横线」三个独立符号硬塞在一枚小图标里；对比主流音频标杆（Spotify 仅三道弧、Pocket Casts 仅双开口圆环、Apple Music 仅单音符、小宇宙仅单几何圆点），现代极简图标的核心法则只有一个——**一个纯净几何符号 + 柔和纸感浅底 + 极小色块占比**。
- **底板统一规范**：米白纸感微渐变（`#FCFBF8 → #F2ECE2`）+ `4px` 浅沙描边 `#E5DDD0`，彻底告别大面积深棕砖块感；在浅色与深色壁纸上都通透柔和。
- **主推方案 A「声环留声 · 实心芯」**（参考 Pocket Casts / Overcast 与留声机唱纹）：
  1. **双层开口同心圆弧**：圆心 `(256, 256)`，外环半径 `146`（透明度 `30%`）、内环半径 `94`（透明度 `66%`），统一向右侧播放方向开口，端点圆头。既呼应 App 内的「留声机唱片卡」，又像声波向外扩散；
  2. **圆润微播放芯**：中心仅留一枚极小巧的圆角实心播放芯（陶土微渐变 `#CE6D43 → #A64D2A`），色块面积极克制，负责锚定视觉焦点；
  3. **三档尺寸变体**：主标（≥ 48px，双环 + 播放芯）、紧凑标（≤ 32px，精简为单环加粗 `34` + 播放芯，16px 依然干净锐利）、单色标（24dp 通知栏与深色面反白）。
- **同步提供的 3 套备选提案**（均已内置于 `docs/ui-prototype.html`，点击任意提案卡即可全页实时联动预览 48/32/24/16px 与 App 内实景）：
  - **方案 B「声环留声 · 纯线稿」**：中心播放键同样改为圆角线稿，全图零实心色块，最为通透轻盈；
  - **方案 C「云波五律」**：5 根等距圆角声波细柱，底部齐平如云底、顶部高低起伏如流云，单语法极简（小尺寸自动精简为 3 柱）；
  - **方案 D「序律三线」**：三条渐进长度水平圆角音轨条，精准呼应「云序」的有序队列基因，借格式塔暗含向右播放动势。
- **工程落地兼容**：选定最终方案后，更新 `design_output/logo/yunxu_logo.svg`、`render_png.py` 与 `deploy_icons.py`，按尺寸自动选用主标 / 紧凑标 / 单色标，一键生成 Android `mipmap-mdpi ~ xxxhdpi`、Adaptive Icon 前景/单色层与 iOS `AppIcon.appiconset` 共 20 张图标。

### 3.2 配套线性图标系统（28 枚）
标识与界面图标必须出自同一支笔，否则「云是线、图标是面」会立刻露怯。

- **规格**：`24 × 24` 网格、`1.75` 描边、端点与拐角全圆、四周留 `2px` 安全边距、`16px` 为可用下限（再小改用实心轮廓）。
- **清单（28 枚）**：`home` `folder` `playlist` `settings` `play` `pause` `prev` `next` `rewind` `forward` `queue` `sort` `moon` `speed` `repeat` `shuffle` `search` `filter` `more` `chevron` `collapse` `check` `cloud` `clock` `cc` `lyrics` `wave` `timer`。
- **语义分工**：`rewind` / `forward` 只画圆弧箭头，数字 `15` 由页面叠加（`AudioPage` 的步进键），这样同一枚图标可复用到 10s / 30s 步长；`settings` 用两条带旋钮的滑杆而非齿轮，`16px` 下仍不糊。
- **Flutter 落地**：不新增图标字体依赖 —— 优先映射 Material Icons（Outlined，同为 24 网格 / 2px 笔触，与 `1.75` 肉眼无差），品牌专属的 `cloud` / `wave` / `lyrics` / `timer` 用 `AppIcons` 内 `CustomPainter` 手绘；集中放在 `lib/ui/icons.dart`，业务代码只允许 `AppIcons.xxx`，禁止散落 `IconData` 字面量。
- 原型中的 28 枚图标已全部可点视（见 `docs/ui-prototype.html` 的「配套线性图标系统」一节，含 24 / 20 / 16 三档尺寸对照）。

### 3.3 色彩与暗黑模式双轨 Token（`AudioTone` & `AppPalette`）
保留全仓唯一色源纪律（严禁业务组件硬编码 `Color(...)`），正式打通**浅色 / 深色 / 跟随系统**三态切换：

| 语义角色 | 浅色模式（纸感暖陶 `AudioTone`） | 深色模式（夜读暖曜 `AppPalette`） | 适用场景 |
|---|---|---|---|
| `bg` 页面主背景 | `#F5F2EC`（温润米白纸底） | `#181614`（深焙暖曜黑，微调加深拉开层次） | Scaffold 背景、顶栏底色 |
| `surface` 一级卡片面 | `#FFFFFF`（纯净卡片白） | `#24211E`（暖炭卡片底） | 续播卡、分组设置卡、MiniPlayer、弹窗 |
| `sand` 次级容器/胶囊 | `#EDE4D8`（浅暖沙） | `#332E29`（深暖褐沙） | 选中行底、胶囊按钮、格式徽章底 |
| `sandDeep` 轨道/分割线 | `#E6DED3`（沙灰） | `#423B35`（暗沙灰） | Slider 未播轨道、细分割线 |
| `taupe` 描边/禁用态 | `#C2B8A9`（暖褐灰） | `#6B6055`（暗暖灰） | 卡片极细描边、非媒体置灰图标 |
| `ink` 一级主文字 | `#21201D`（暖墨黑） | `#F2EDE6`（柔和羊皮纸白） | 标题、正文文件名、主图标 |
| `muted` 二级元信息 | `#8A8074`（暖石灰，微提对比度达 AA） | `#9E958A`（暖银灰） | 时长、路径、文件大小、次级说明 |
| `accent` 品牌主色 | `#B85C38`（经典陶土） | `#D97752`（提亮暖陶，暗底对比度 ≥ 5.2:1） | 播放主圆键、激活进度、当前播放高亮 |
| `success` 已播完语义 | `#4E7A5B`（鼠尾草绿，低饱和融入暖调） | `#6FA07E`（柔和苔绿） | 「已播完」徽章与完成态打勾 |

### 3.4 字体排版尺度（Typography Scale）
- 数字时间与集数百分比全面启用 `FontFeature.tabularFigures()`（等宽数字），杜绝播放读秒与拖动进度条时文字左右抖动；
- 长文件名策略：全屏 `AudioPage` 标题支持 **最多 2 行居中平衡折行（字号自适应：短标题 `24pt w700`，超 24 字长标题自动收敛至 `19pt w600`）**；列表行支持 **2 行紧凑显示或单行尾部智能保留集数信息**，确保《凡人修仙传 第0128集 风起天南.mp3》不会把最关键的集数截断成 `...`。

## 四、核心页面与高频微能力详细改版设计

### 4.1 全局壳层：一体化悬浮 `MiniPlayerBar` + 胶囊底栏
1. **视觉升级**：
   - `MiniPlayerBar` 采用 `surface` 圆角胶囊卡（`radius: 22`）+ `1px` `sandDeep` 精致内描边 + 轻柔暖墨投影；
   - 左侧 `44pt` 圆角缩略图（音频播放时中心带微小的三柱动态律动指示器）；中部上行显示曲目名、下行显示**「当前状态/剩余时长 · 父目录名」**；底部紧贴卡片下沿内嵌一条 `2.5pt` 贯穿式陶土进度细线；右侧为 `40pt` 陶土实心圆播放键 + 快捷「下一曲」轻触图标。
2. **手势增强**：
   - **点击展开**：触发自底向上自定义模态路由（`PageRouteBuilder`）平滑展开全屏 `AudioPage`；
   - **左右滑动切歌**：在 `MiniPlayerBar` 文字区左右轻扫直接触发 `previous()` / `next()`，伴随曲目名横向位移淡入过渡与轻触觉反馈（`HapticFeedback.selectionClick()`）。
3. **全局防遮挡规范**：提取统一的底部安全留白常量 `kMiniPlayerReservedPadding = 84.0`，当 `playback.current != null` 时自动为 4 个 Tab 列表底部注入内边距，彻底消除最后一行被悬浮条遮挡的问题。

### 4.2 Tab 1「首页」：升级为真正的「收听中枢（Listening Hub）」
告别原先单薄且重复的列表，重构为四层清晰的信息流：
1. **品牌抬头栏**：左侧展示新「云序」Logo 微标 + 标题，右侧展示**站点状态胶囊**（如 `● 家里NAS · 已连接`，点击可快速跳转设置或测试连通性）。
2. **模块一：常驻「正在收听 / 继续播放」英雄卡（Hero Resume Card）**：
   - **不再在开播后消失**：`idle` 恢复态显示「继续上次收听」，`playing / paused` 态显示「正在播放」与实时进度百分比；
   - 卡片采用暖沙底纹装饰，展示媒体类型胶囊（`音频 · FLAC` 或 `视频 · MKV`）、2 行完整标题、所属目录路径、醒目的进度条（如 `18:42 / 45:10 · 41%`）以及主行动大按钮。
3. **模块二：「最近播放」横向/精简回顾流（激活 DB 既有 `historyStream`）**：
   - 零数据库改动直接绑定 `db.historyStream(limit: 10)`；
   - 展示最近听过/看过的单集紧凑卡片（含父目录名与播放时间提示），支持一键清空历史或点击直接回到该目录续播。
4. **模块三：「我的播单」双列/精简精选卡片区**：
   - 首行固定高亮「当前播放队列（共 N 集）」入口卡，下方以更具呼吸感的圆角卡片展示自建播单（附「新建播单」快捷虚线/轻按钮），与第 3 个 Tab 的重度管理视图形成轻重分工。

### 4.3 Tab 2「文件」：面向追更与听书的网盘目录浏览器
1. **胶囊面包屑 + 目录内即时过滤栏**：
   - 顶栏右侧新增 `🔍 筛选` 图标，点击原地展开轻量圆角搜索框，对当前目录 `_entries` 进行零网络开销的实时子串忽略大小写过滤（例如在 300 集目录里输入 `128` 秒找第 128 集），同时右上角支持一键切换排序方式（自然排序 / 名称 / 修改时间）。
2. **文件列表级「播放进度透出」（杀手级体验提升）**：
   - 新增批量/流式读取当前目录路径对应的 `playProgresses` 映射；
   - **未播媒体**：显示精致暖沙圆角图标底 + 文件大小 + 格式标签（`FLAC` / `MP3` / `MP4`）；
   - **播到一半的媒体**：标题下方渲染 `2.5pt` 陶土进度细条，副标题高亮显示 `已播 64% · 28:15 / 44:00`；
   - **已看完/听完的媒体**（或历史记录已播完）：显示温润鼠尾草绿 `✓ 已播` 微型胶囊；
   - **非媒体文件**：柔和暖灰降噪呈现，视觉层次一目了然。
3. **多选操作岛**：长按进入多选态时，底部浮现圆角毛玻璃/暖白浮动操作岛（全选 / 反选 / 加入播单主按钮），带平滑上浮动画。

### 4.4 全屏音频页 `AudioPage`：一屏锁定 + 留声机唱片/LRC 歌词 + 四大微能力
1. **一屏锁定架构与下拉收起**：
   - 移除原有的整页 `CustomScrollView` 长列表，采用弹性比例布局（`Expanded` 封面/歌词舞台 + 固定比例信息与控制区），完美适配小屏（360×640）与大屏（430×932）且绝不溢出或误滚；
   - 顶栏左侧图标由返回箭头改为向下的收起箭头 `⌄`，全页支持纵向轻扫下拉跟手关闭。
2. **上半屏双态舞台：「暖陶留声机唱片卡」⇄「同目录 `.lrc` 滚动歌词」**：
   - **状态 A（封面 / 留声机态）**：
     - 若网盘提供 `thumb` 缩略图：圆角铺满 + 柔和弥散阴影；
     - 若无缩略图（默认常态）：绘制全新的**「暖陶留声机唱片卡」**——暖沙网格纸底（`GridBackdrop`）上居中一枚精密同心圆声波黑胶盘，右上角嵌有动态提取的格式音质徽章（如 `FLAC · 无损` / `MP3`），右下角斜置一枚极简几何唱臂指示器（播放时轻搭唱盘，暂停时微抬 `12°`）；
     - **长按封面区**：如同视频页一样触发 `2.0x / 3.0x` 临时倍速快进，顶部浮现胶囊提示，松手即恢复原速。
   - **状态 B（LRC 歌词态）**：
     - 新增纯 Dart `core/lrc_parser.dart` 与同目录同前缀 `.lrc` 自动匹配（复用 `subtitle_match` 思想，拉取几 KB 文本解析时间戳）；
     - 当检测到同目录存在 `.lrc` 时，舞台右下角浮现 `词` 胶囊开关，点击即可通过 `AnimatedSwitcher` 丝滑切换为居中高亮滚动歌词列表（支持点击某句歌词直接跳到对应秒数！无 `.lrc` 时零打扰隐藏）。
3. **下半屏控制区：五键对称主控 + 按压增粗进度条 + 四键胶囊底栏**：
   - **进度条**：平时 `4pt` 轨道，手指按住拖动（`_dragMs != null`）时平滑动画增粗至 `8pt`，两侧等宽数字实时显示 `当前时间` 与 `-剩余时间`（点击右侧可切换显示 `总时长`）；
   - **五键对称主控行**：
     `[ ⏮ 上一曲 ]   [ ↺ 15s ]   [ ● 84pt 陶土播放/暂停圆键 ]   [ 15s ↻ ]   [ ⏭ 下一曲 ]`
   - **四键胶囊工具栏**：
     1. **`倍速胶囊`（如 `1.25x`）**：点击弹出升级版倍速面板——上方为 `0.5x ~ 3.0x` 连续 `0.1x` 步进滑杆与 `[-0.1] [+0.1]` 微调键，下方为常用预设快捷胶囊（`0.75x / 1.0x / 1.25x / 1.5x / 2.0x`）；
     2. **`睡眠定时`（新增）**：支持 `关闭 / 15分钟 / 30分钟 / 45分钟 / 60分钟 / 播完当前这集停`；开启后工具栏图标变为高亮陶土色并实时显示剩余分钟数（如 `🌙 24m` 或 `🌙 本集末`）；
     3. **`循环模式`**：列表循环 / 单曲循环 / 随机播放切换，配轻吐司或状态文案提示；
     4. **`播放队列`（带 `12/48` 进度角标）**：点击呼出 `72%` 屏高的圆角队列抽屉，打开瞬间自动将当前播放项滚动至可视区中央，支持在抽屉内一键定位当前集与快速切歌。

### 4.5 视频页 `PlayerScreen`、播单页与设置页统一焕新
- **视频页 `PlayerScreen`**：
  - 竖屏下半区升级为「剧集标题卡 + 外置快捷胶囊行（倍速 / 字幕 / 音轨 / 加入播单，无需点开拥挤的小视频窗口就能直接调字幕与倍速！）+ 带播放中声波标记的暖陶选集卡片列表」；
  - 横屏全屏控制层顶栏与底栏采用更通透的渐变暖墨遮罩 + 圆角胶囊控件。
- **播单页 & 播单详情页**：
  - 播单列表改为带左侧叠层封面感图标的圆角白卡；详情页保留并美化「上次播到」书签卡，拖拽手柄与左滑删除动效对齐暖陶色系。
- **设置页 `SettingsPage`**：
  - 全面采用 **Inset Grouped 圆角分组白卡** 布局：「服务器连接卡（带实时连接状态徽章与一键测试动效）」、「外观与显示卡（新增：浅色 / 深色 / 跟随系统 分段选择器）」、「浏览与播放偏好卡（排序、默认循环、后台音频开关、三档缓冲策略可视化胶囊说明）」、「关于云序卡（展示新 Logo 与版本信息）」。

## 五、六大克制高帧率交互动画规范（Skia 120fps 友好）

严格规避大面积实时 `BackdropFilter` 模糊，全部基于硬件加速的 `Transform`、`Opacity` 与物理弹簧曲线实现：

| 编号 | 动效名称 | 触发时机与表现细节 | 时长与曲线参数 |
|---|---|---|---|
| **M1** | **MiniPlayer ⇄ 全屏播放器跟手模态转场** | 点击 `MiniPlayerBar` 时全屏页自底向上带圆角展开，封面/留声机通过 `Hero` 共享过渡；顶部下拉时页面随手指位移实时轻微缩小（`scale: 1.0 → 0.94`）并露出后方页面，超阈值松手顺滑收起。 | 展开 `320ms` `Curves.easeOutQuart`；收起 `260ms` |
| **M2** | **主播放键弹簧按压与形态丝滑变形** | 按下 84pt 陶土大圆键时缩放至 `0.92x` 并触发 `HapticFeedback.lightImpact()`，松手带微弹性回弹；内部 `▶ / ⏸` 使用 `AnimatedIcon(AnimatedIcons.play_pause)` 连续变形；缓冲态外圈叠加柔和旋转陶土光弧。 | 按压 `90ms`；回弹 `220ms` `Curves.easeOutBack` |
| **M3** | **暖陶留声机匀速微旋与阻尼停盘** | 音频 `playing` 时同心声波唱盘以 `24 秒/圈` 极低速优雅旋转，右上角唱臂轻落；切为 `paused` 时唱臂微抬 `12°`，唱盘经 `600ms` 减速阻尼平滑停稳（绝不突兀跳回原点）。 | 唱臂 `240ms` `Curves.easeInOutCubic` |
| **M4** | **进度条按压增粗与时间读数强调** | 手指按住进度条拖动时，轨道高度由 `4pt` 动画增粗至 `8pt`，当前时间字号微放大并加深为陶土主色，松手后 `180ms` 平滑回缩。 | `160ms` `Curves.easeOutCubic` |
| **M5** | **`±15s` 步进微旋与数值浮标反馈** | 点击快退/快进 15s 时，环形箭头图标沿方向轻转 `35°` 回弹，同时按钮上方轻盈浮现 `-15s` / `+15s` 微胶囊渐隐，给盲操明确的视觉确认。 | `280ms` `Curves.easeOutCubic` |
| **M6** | **MiniPlayer 横滑切歌与面板交错入场** | 横滑 `MiniPlayerBar` 切歌时标题横向滑出/滑入；目录进入下级或弹出底部抽屉（队列/定时/倍速）时内容带 `12px` 轻微上移渐显。 | `200ms` `Curves.easeOutCubic` |
