Yunxu 云序 UI 优化方案

一屏锁定的全屏播放器、会显示收听进度的网盘目录、能读懂长文件名的首页。这份方案建立在三类主流播放器的拆解之上，并沿用项目已有的暖陶色板与零元数据现实：大多数云端音频没有封面、没有标签，只有目录和集数。

长音频 × 音乐双修 暖陶 + 深色模式 一屏锁定 + 队列抽屉 首页 = 收听中枢 睡眠定时 / LRC 歌词 / 目录进度 阻尼微动效 · Skia 120fps

标识重构：主流极简几何

摒弃具象云朵堆砌，回归 Spotify / Pocket Casts / Apple 式的纯净单符号 · 点击下方任意提案可全页实时预览
v1.0 初版

深棕实底 + 具象云拼贴

整块深棕压迫感强；云朵 + 三角 + 三条细线三个独立符号硬塞在一张图里，缩小后杂乱缺乏现代感。

  • 视觉元素过多（三套图形叠在一起）
  • 深色实底面积 100%，放在桌面显得沉重
  • 底部 10px 细线在 48px 图标上几乎糊掉
主推方案 · 声环留声

双层声环 + 圆润微播放芯

参考 Pocket Casts / Overcast 与小宇宙的极简几何思路：去掉具象云朵，用两道向右开口的同心唱纹环抱一枚微圆角播放芯，既有留声机唱片感，又有声波向外扩散的流动韵律。

  • 米白纸感浅底 + 纯粹几何线条，色块面积极小且克制
  • 和 App 内「留声机唱片卡」视觉同源，从桌面点进播放器一气呵成
  • 所有曲率基于精准同心圆计算，无任何尖角或杂乱接缝，16px 依然干净

这台原型里能摸到的东西

所有色值、圆角、间距都取自项目现有的 AudioTone 与 AppPalette，不是另起一套视觉。切到「设置 → 外观」可以直接把整台机器切进深色。

  • 播放 / 暂停：大圆键按压回弹，唱片随之阻尼起转与停稳，唱臂抬起落下。
  • 拖动进度条：按下时轨道从 4px 增粗到 8px，时间实时跟随，松手回缩。
  • ±15 秒：点击有微旋与浮标反馈，进度真实变化，回头重听一句不用拖。
  • 队列抽屉：从底部滑出并自动定位到当前集，长队列不用翻页。
  • 睡眠定时：选完底栏立刻变成剩余分钟，长音频哄睡的关键开关。
  • 文件页：每集自带已播百分比与「已播」徽章，扫一眼就知道听到哪。
  • 首页 / 文件 / 设置：点底部 mini 播放条可随时回到播放器。

竞品拆解：各取所长

按云序的三个真实约束筛选，不是照着音乐 App 复刻
赛道值得吸收不该照搬
播客与有声书小宇宙 · Castro · Pocket Casts 纸感暖调营造陪伴感；±15s 贴着大播放键做盲操；列表直接显示「已播完 / 剩余多久」；睡眠定时与 0.1x 精细倍速。 社交评论流、订阅发现页、ShowNotes 富文本——对纯网盘播放器都是噪音。
无损音乐Apple Music · 椒盐音乐 一屏锁定 + 自底向上模态转场，下拉跟手收起；按住进度条增粗；封面与滚动歌词原位切换；底部抽屉队列自动定位当前曲。 依赖大封面的流体模糊背景——网盘音频大多无封面，且在关闭 Impeller 的机型上纯属性能负担。
私有云 / NASInfuse · Plexamp 从扩展名生成 FLAC / MKV 音质徽章，零元数据成本建立专业感；胶囊面包屑 + 目录内即时过滤；首页「继续收听」英雄卡。 影视海报墙刮削——个人云盘目录命名随性，元数据误配率高，违背轻量定位。

六处交互动效

只用 Transform / Opacity / 轻量 CustomPainter，不碰大面积实时模糊
01

Mini 播放条 ⇄ 全屏原型可试

点击 mini 条，全屏页自底向上带圆角展开；封面以 Hero 共享元素飞入。下拉时页面随手位移并轻微缩小，露出后方页面。

展开 320ms · easeOutQuart / 收起 260ms
02

主播放键弹簧回弹原型可试

按下缩到 0.92 并给一次轻触觉反馈，松手带回弹；▶ 与 ⏸ 用 AnimatedIcon 连续变形；缓冲时外圈浮现柔和光弧。

按压 90ms · 回弹 220ms easeOutBack
03

唱片微旋与阻尼停盘原型可试

播放时 24 秒一圈极慢旋转，唱臂轻落；暂停时唱臂抬起 12°，唱盘经 600ms 阻尼减速停稳，不会突兀跳回原点。

15°/s · 阻尼系数 4.5
04

进度条按压增粗原型可试

按住拖动时轨道 4px 平滑增至 8px，当前时间放大并转为陶土色；松手 180ms 回缩。

160ms easeOutCubic
05

±15s 微旋浮标原型可试

点击步进键，环形箭头沿方向轻转 35° 回弹，按钮上方浮出「−15s / +15s」并渐隐，盲操也有确认。

280ms easeOutCubic
06

横滑切歌与面板入场

在 mini 条文字区左右轻扫直接切上一首/下一首；目录进入下级、弹出队列或定时面板时，内容带上移渐显。

200ms easeOutCubic · 视差 18px
