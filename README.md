# 云序（OpenListPlayer）

> 一款面向手机的云端音视频播放器：通过 openlist 播放天翼云盘中的音频与视频，补齐官方客户端在倍速、排序、长音频体验与断点续播上的短板。

## 一、项目简介

### 1.1 背景

天翼云盘中存有大量音频、视频资源，但其官方 App 在「纯播放」场景下体验不足：缺少倍速播放、文件缺乏自然排序、播放不稳定且失败后难以保留播放位置，常常重新从头播放。对于追剧、听书、播客与整目录连续播放用户，这些缺陷直接影响使用。

### 1.2 目的

本项目是基于 [openlist](https://github.com/OpenListTeam/OpenList) 开源项目的**前端 App**，本身不直接对接天翼云盘，而是以 openlist 提供的云盘服务为后端：

- **服务端**：部署 openlist 并挂载天翼云盘，对外提供统一的云盘与文件直链服务；手机与服务器之间通过 openp2p 等组网方式连通。
- **手机端**：本 App 通过 HTTP 访问服务器上的 openlist 服务，拉取目录、文件直链及同目录 `.lrc` 歌词文本，交由本地播放器解码播放。

项目目标是提供一个**轻量、温润、稳定、可续播**的手机端播放体验，专注解决长音频与剧集播放痛点，而非重新实现网盘功能。

| 项目属性 | 说明 |
| --- | --- |
| 应用名称 | 云序（YUNXU），包名 `openlistplayer` / `com.songyaning.openlistplayer` |
| 项目类型 | Flutter 移动端 App（Android / iOS） |
| 角色定位 | openlist 的前端播放器，非网盘服务端 |
| 当前版本 | 1.0.0（pubspec `1.0.0+1`） |
| 视觉主题 | 纸感暖陶浅色 / 夜读暖曜深色 / 跟随系统（三态持久化） |
| 认证方式 | v1 单站点、guest 免认证，`token` 为预留扩展位 |

## 二、核心痛点与解决方式

| 痛点 | 天翼云盘 App 现状 | 云序的解决方式 |
| --- | --- | --- |
| **缺少倍速与长音频控件** | 不支持倍速与听书微调 | 支持全局倍速与 0.1x 精细调节、长按临时 3x 快进（松开恢复）、`±15s` 步进、睡眠定时（倒计时 / 播完本集停） |
| **缺少自然排序** | 按字典序排列，`2` 排在 `10` 之后，剧集/章节顺序错乱 | 零分配流式自然排序比较器（支持任意超长数字段与前导零等价比较，`2 < 10 < 100`），文件列表与播放队列共用同一排序逻辑 |
| **播放不稳定** | 网络波动时易中断、跳转或从头开始 | 三档缓冲策略（流畅 30s / 稳健 60s / 激进 120s）、弱网无限等待不自动跳曲、失败自动重试（最多 2 次）并从最近位置断点重连 |
| **失败后难记录位置、易从头播放** | 失败后播放位置丢失，重新打开回到片头 | 每 5 秒落盘进度，切歌/跳转/暂停/退后台均立即记录；会话恢复保存队列与位置；全局进度仅在 ≥95% 才视为看完并清除，播单独立进度互不干扰；重试绝不回片头 |

## 三、架构与数据流

### 3.1 整体架构

```mermaid
flowchart LR
    A[天翼云盘<br/>云端音视频文件] -->|服务端挂载对接| B[openlist<br/>云盘与直链服务]
    B -->|HTTP REST API| C{{组网通道 / 局域网}}
    C -->|列目录 / 取直链 / 拉歌词| D[云序 OpenListPlayer<br/>手机端 App]
    D -->|raw_url 或 /d 代理| E[media_kit / mpv<br/>解码播放]
    E --> F[倍速 · 续播 · 外挂字幕 · LRC 歌词 · 后台播放]
```

- **openlist 服务端**：对接天翼云盘，提供目录列表（`/api/fs/list`）、文件直链（`/api/fs/get`）、连接探测（`/ping`）等 REST API。
- **组网连通**：App 侧只感知一个 HTTP/HTTPS 基础地址（`baseUrl`，支持子路径反代），具体 openp2p 组网配置与服务端部署文档**待补充**。
- **App 客户端**：通过 `OpenListClient` 调用上述 API，自动处理请求头格式化、相对/协议相对直链解析与 403 刷新静默降级，获取直链后由 `media_kit`（mpv 内核）解码播放。

### 3.2 一次播放的数据流

1. 用户在**文件浏览器**中浏览 openlist 目录，App 调用 `/api/fs/list` 拉取条目并按所选排序方式展示，同时叠加本地数据库中的目录级播放进度与「已播」状态。
2. 点击媒体文件时，取当前目录内全部音视频构建「正在播放」队列并从所点项开播；从播单启动时整张播单复制为队列，按播单独立续播指针恢复。
3. App 调用 `/api/fs/get` 获取文件直链：`raw_url` 可用时直接使用（自动补全站内相对或 `//` 协议相对 URL），否则回退到正确百分号编码后的 `/d` 代理地址并附带签名与请求头（`header`）。
4. `PlaybackController` 以直链打开播放器，读取历史进度续播（≥95% 视为看完则从头播），按复合键恢复内置音轨/字幕偏好，并自动挂载同目录外挂字幕或拉取同目录 `.lrc` 歌词。
5. 播放过程中定期将进度、历史、轨道偏好与会话状态写入 drift SQLite；弱网失败时从最近位置重取直链重连（底层流自行恢复时自动取消挂起重试）。

## 四、主要功能模块

| 模块 | 功能说明 |
| --- | --- |
| **首页收听中枢** | 品牌抬头与站点状态胶囊；常驻「继续播放 / 正在收听 / 已暂停」英雄卡；「最近播放」回顾流（最近 10 条展示、支持弹窗清空与快速复播）；「当前播放队列」与精选播单入口 |
| **文件浏览器** | 胶囊面包屑导航、目录内零网络开销即时筛选、自然排序 / 名称 / 修改时间切换、文件级播放进度细条与「已播」徽章、非媒体文件降噪、下拉刷新（guest 403 静默降级读缓存）、长按多选浮动操作栏加入播单 |
| **音频播放** | 一屏锁定布局 + 下拉收起；留声机唱片卡与同目录 `.lrc` 滚动歌词原位切换；按压增粗进度条；含 `±15s` 的五键主控；睡眠定时（倒计时 / 播完本集停）；0.1x 精细倍速调节；底部队列抽屉 |
| **视频播放** | 竖屏内嵌 16:9（含竖屏快捷控制与懒加载队列）、横屏全屏、手势快进 / 亮度 / 音量 / 双击 / 长按临时 3x 倍速（顶部胶囊提示）、倍速/字幕/音轨/播放模式控制条、屏幕常亮；混合队列跨音视频切歌自动互切页面 |
| **悬浮迷你播放条** | 胶囊卡 + 底部贯穿进度细线 + 动态声波律动指示器；点击展开播放页（idle 态自动续播），左右轻滑直接切上下曲 |
| **字幕与音轨** | 同目录外挂字幕忽略大小写前缀分桶自动匹配（精确同名优先）、逐条独立容错与复用去重、请求头隔离防泄露、手动选字幕与 ±60s 延迟调节、按文件使用复合键记忆内置音轨/字幕偏好 |
| **播单与独立进度** | 支持跨目录自建播单、手动排序与去重；每个播单独立记录每个文件的断点和「上次播到哪个文件」，与全局进度及其他播单互不影响；看完标记「已看完」，「继续播放」自动跳到下一个未看完条目 |
| **后台播放** | 锁屏 / 通知栏控件（`audio_service`，支持播放/暂停、上下曲与 ±10s 快进快退）、耳机拔出暂停、来电中断暂停、「视频退后台继续播放声音」开关 |
| **外观与设置** | 服务器地址规范校验与连接测试、三态主题切换（纸感暖陶浅色 / 夜读暖曜深色 / 跟随系统）、排序方式、默认播放模式、视频后台声音、三档缓冲策略 |

### 4.1 进度与重连规则

| 规则 | 取值 / 行为 |
| --- | --- |
| 记录频率 | 每 5 秒一次，并在暂停、切歌、拖动进度条、退后台时立即记录 |
| 最短时长 | 总时长 < 10 秒的内容不记录进度 |
| 看完判定 | 进度 ≥ 95% 视为看完：全局进度删行（下次从头播放）；播单进度保留行并标记「已看完」 |
| 续播判定 | 未看完则下次从记录位置续播；`idle / error / opening` 态下 seek 同步更新待恢复断点 |
| 历史裁剪 | `playHistories` 自动保留最近 20 条记录 |
| 重试策略 | 自动重试最多 2 次（间隔 800ms），从最近位置重取直链，绝不回片头；底层流自行恢复时立即取消挂起重试；仍失败则展示错误态并提供「重试 / 跳过」 |

### 4.2 缓冲策略

| 档位 | 预读时长 | 缓冲大小 |
| --- | --- | --- |
| 流畅 | 30s | 64 MiB |
| 稳健（默认） | 60s | 160 MiB |
| 激进 | 120s | 320 MiB |

## 六、使用与开发

### 6.1 使用者

1. **准备服务端**：在服务器上部署 openlist 并挂载天翼云盘，通过局域网或 openp2p 等方式确保手机可访问 openlist 的 HTTP/HTTPS 地址。
2. **配置站点**：打开「云序」→「设置」→ 填写「名称（可选）」与「OpenList 地址」（如 `http://192.168.2.29:5244`）→ 点击「测试连接」→「保存」；同一页面可切换浅色 / 深色 / 跟随系统主题。
3. **浏览与追更**：进入「文件」tab 浏览目录，可用右上角筛选框快速定位剧集，文件行直接显示播放进度条与「已播」状态；长按可批量加入播单。
4. **收听与观看**：点击音视频文件即从当前目录开播；音频页可点击唱片卡切换同目录 `.lrc` 歌词、使用 `±15s` / 0.1x 倍速 / 睡眠定时与队列抽屉；视频页支持横屏全屏与手势调节。
5. **随时续播**：再次打开 App 后，首页常驻英雄卡与底部迷你条均可一键续播上次进度，也可从「最近播放」或「我的播单」继续。

### 6.2 开发者

```bash
# 1. 获取依赖
flutter pub get

# 2. 生成 drift 数据库代码（修改 app_database.dart 后需重新执行）
dart run build_runner build --delete-conflicting-outputs

# 3. 静态分析与测试（若终端启用了全局 HTTP 代理，需对 127.0.0.1,localhost 绕过代理）
flutter analyze --no-pub
flutter test

# 4. 真机调试运行
flutter run

# 5. 集成测试（需设备 + 本机 localhost:5244 的 OpenList）

# 6. 打包（示例）
flutter build apk --release --target-platform android-arm64
flutter build ios
```

设计文档与交互原型见 `docs/ui-optimization-plan.md` 与 `docs/ui-prototype.html`；深度代码审查归档见 `docs/iterative-review-2026-11-25.md`。

## 七、已知限制

| 限制 | 说明 |
| --- | --- |
| 认证与多站点 | v1 仅支持单站点、guest 免认证；`token` 字段为预留扩展位，暂不支持登录鉴权与多站点切换 |
| 媒体与歌词识别 | 依赖扩展名白名单判定音视频/字幕/歌词，无扩展名或被改名的文件无法识别；支持格式见 `lib/core/media_types.dart` 与 `lib/core/lrc_parser.dart` |
| 外挂字幕与歌词 | 自动匹配**同目录、同前缀**的字幕（`.srt`/`.ass`/`.vtt`）与 `.lrc` 歌词文件；命名不匹配的字幕可手动选择 |
| iOS 模拟器 | 受 mpv 在模拟器上的限制，音频设备无法初始化，模拟器内仅能无声播放；真机不受影响 |
| 平台适配与签名 | Android Release 包目前仍使用 debug 签名；视频硬解与 Impeller 开关针对真机实测配置，升级引擎或依赖前需真机验证 |
| 服务端部署 | openlist 挂载天翼云盘、openp2p 组网的具体部署文档**待补充** |
