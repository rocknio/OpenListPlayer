# OpenListPlayer

> 一款面向手机的云端音视频播放器：通过 openlist 播放天翼云盘中的音频与视频，补齐官方客户端在倍速、排序与断点续播上的体验短板。

## 一、项目简介

### 1.1 背景

天翼云盘中存有大量音频、视频资源，但其官方 App 在"纯播放"场景下体验不足：缺少倍速播放、文件缺乏自然排序、播放不稳定且失败后难以保留播放位置，常常重新从头播放。对于追剧、听书、连续播放整目录内容的用户，这些缺陷直接影响使用。

### 1.2 目的

本项目是基于 [openlist](https://github.com/OpenListTeam/OpenList) 开源项目的**前端 App**，本身不直接对接天翼云盘，而是以 openlist 提供的云盘服务为后端：

- **服务端**：部署 openlist 并挂载天翼云盘，对外提供统一的云盘与文件直链服务；手机与服务器之间通过 openp2p 组网连通。
- **手机端**：本 App 通过 HTTP 访问服务器上的 openlist 服务，拉取目录与文件直链，交由本地播放器解码播放。

项目目标是提供一个**轻量、稳定、可续播**的手机端播放体验，专注解决上述四类痛点，而非重新实现网盘功能。

| 项目属性 | 说明 |
| --- | --- |
| 项目类型 | Flutter 移动端 App（Android / iOS） |
| 角色定位 | openlist 的前端播放器，非网盘服务端 |
| 当前版本 | 1.0.0（pubspec `1.0.0+1`） |
| 认证方式 | v1 单站点、guest 免认证，token 为预留扩展位 |

## 二、核心痛点

| 痛点 | 天翼云盘 App 现状 | 本 App 的解决方式 |
| --- | --- | --- |
| **缺少倍速播放** | 不支持倍速 | 支持全局倍速设置、播放中调节倍速、长按临时 3x 快进（松开恢复） |
| **缺少自然排序** | 按字典序排列，`2` 排在 `10` 之后，剧集/章节顺序错乱 | 实现自然排序比较器，数字段按数值比较（`2 < 10 < 100`），文件列表与播放队列共用同一排序逻辑 |
| **播放不稳定** | 网络波动时易中断、跳转或从头开始 | 三档缓冲策略（流畅 30s / 稳健 60s / 激进 120s）、弱网无限等待不自动跳曲、失败自动重试（最多 2 次）并从最近位置断点重连 |
| **失败后难记录位置、易从头播放** | 失败后播放位置丢失，重新打开回到片头 | 每 5 秒落盘进度，切歌/跳转/暂停/退后台均记录；会话恢复保存队列与位置；仅当播放进度 ≥95% 才视为看完并从头播；重试绝不回片头 |

## 三、架构与数据流

### 3.1 整体架构

```mermaid
flowchart LR
    A[天翼云盘<br/>云端音视频文件] -->|服务端挂载对接| B[openlist<br/>云盘与直链服务]
    B -->|HTTP REST API| C{{openp2p 组网通道}}
    C -->|列目录 / 取直链| D[OpenListPlayer<br/>手机端 App]
    D -->|raw_url 或 /d 代理| E[media_kit / mpv<br/>解码播放]
    E --> F[倍速 · 续播 · 外挂字幕 · 后台播放]
```

- **openlist 服务端**：对接天翼云盘，提供目录列表（`/api/fs/list`）、文件直链（`/api/fs/get`）、连接探测（`/ping`）等 REST API。
- **openp2p**：负责手机与服务器之间的组网连通；App 侧只感知一个 HTTP 基础地址（`baseUrl`）。openp2p 的部署与映射配置**待补充**。
- **App 客户端**：通过 `OpenListClient` 调用上述 API，获取直链后由 `media_kit`（mpv 内核）播放。

### 3.2 一次播放的数据流

1. 用户在**文件浏览器**中浏览 openlist 目录，App 调用 `/api/fs/list` 拉取条目并按自然排序展示。
2. 点击媒体文件时，取当前目录内全部音视频，按排序规则构建"正在播放"队列。
3. App 调用 `/api/fs/get` 获取文件直链：`raw_url` 可用时直接使用，否则回退到 openlist 的 `/d` 代理下载地址；部分驱动附带请求头（`header`）。
4. `PlaybackController` 以直链打开播放器，读取历史进度续播（≥95% 视为看完则从头播），并开启动态轨道匹配与外挂字幕加载。
5. 播放过程中定期将进度、轨道偏好、会话状态写入本地数据库；失败时从最近位置重取直链重连。

## 四、主要功能模块

| 模块 | 功能说明 |
| --- | --- |
| **文件浏览器** | 目录列表与面包屑导航、自然排序、非媒体文件置灰、下拉刷新（guest 无刷新权限时静默降级读缓存）、长按多选加入播单 |
| **播放队列** | 点击文件即"同目录音视频整体替换队列"并从该文件开播（自动续播）；支持手动播单（跨目录添加、手动排序、去重）；播放模式支持列表循环 / 单曲循环 / 随机 |
| **视频播放** | 竖屏内嵌 16:9、横屏全屏、手势快进 / 亮度 / 音量 / 双击 / 长按 3x、控制条（倍速、字幕、音轨、播放模式）、屏幕常亮 |
| **音频播放** | 独立音频页，配合 mini 播放条与后台播放 |
| **字幕与音轨** | 同目录外挂字幕自动匹配（同前缀规则，如 `movie.mkv` 匹配 `movie.chs.srt`）、手动选择字幕、字幕延迟调节、按文件记忆音轨/字幕偏好 |
| **进度与续播** | 播放进度持久化、历史记录裁剪（保留最近 20 条）、会话恢复（队列 + 索引 + 位置 + 时长）、失败断点重连 |
| **播单独立进度** | 每个播单各自记录每个文件的断点和"上次播到哪个文件"，与全局进度、其它播单互不影响；进入播单可见"上次播到"的文件与位置，"继续播放"从该文件的该位置恢复（该文件已看完则跳到下一个未看完的条目）；看完的条目显示"已看完" |
| **后台播放** | 锁屏 / 通知栏控件（audio_service）、耳机拔出暂停、来电中断暂停、"视频退后台是否继续播放声音"开关 |
| **设置** | 服务器地址校验与连接测试、排序方式、默认播放模式、视频后台声音、缓冲策略（全局倍速在播放面板内调节并自动持久化） |

### 4.1 进度规则（关键设计）

| 规则 | 取值 / 行为 |
| --- | --- |
| 记录频率 | 每 5 秒一次，并在暂停、切歌、跳转、退后台时立即记录 |
| 最短时长 | 总时长 < 10 秒的内容不记录进度 |
| 看完判定 | 进度 ≥ 95% 视为看完，清除进度记录，下次从头播放 |
| 续播判定 | 未看完则下次从记录位置续播 |
| 播单进度 | 每个播单独立记录每个文件的断点和"上次播到哪个文件"（与全局进度、其它播单互不影响）；看完不删行而是标记"已看完"，"继续播放"时跳过 |
| 重试策略 | 自动重试最多 2 次（间隔约 800ms），从最近位置重取直链，绝不回片头；仍失败则展示错误页，提供"重试 / 跳过" |

### 4.2 缓冲策略

| 档位 | 预读时长 | 缓冲大小 |
| --- | --- | --- |
| 流畅 | 30s | 64 MiB |
| 稳健（默认） | 60s | 160 MiB |
| 激进 | 120s | 320 MiB |

## 六、基本使用流程

### 6.1 使用者

1. **准备服务端（待补充）**：在服务器上部署 openlist 并挂载天翼云盘，通过 openp2p 完成手机与服务器的组网，得到 openlist 的 HTTP 访问地址。
2. **配置站点**：打开 App →「设置」→ 填写「名称（可选）」与「OpenList 地址」（如 `http://192.168.2.29:5244`）→ 点击「测试连接」→ 保存。
3. **浏览文件**：进入「文件」tab，按目录浏览云端音视频（默认自然排序）。
4. **开始播放**：点击音视频文件即从当前目录开播；横屏全屏观看视频，使用手势与控制条调节进度、倍速、字幕与音轨。
5. **继续播放**：退出后再次打开 App，首页「继续播放」卡片会恢复上次的队列与位置；进度未达 95% 时自动续播。

### 6.2 开发者

```bash
# 1. 获取依赖
flutter pub get

# 2. 生成 drift 数据库代码（修改 app_database.dart 后需重新执行）
dart run build_runner build --delete-conflicting-outputs

# 3. 运行
flutter run

# 4. 测试
flutter test
flutter test integration_test/app_test.dart

# 5. 打包（示例）
flutter build apk
flutter build ios
```

## 七、已知限制

| 限制 | 说明 |
| --- | --- |
| 认证与多站点 | v1 仅支持单站点、guest 免认证；`token` 字段为预留扩展位，暂不支持登录鉴权与多站点切换 |
| 媒体识别 | 依赖扩展名白名单判定音视频/字幕，无扩展名或被改名的文件无法识别为媒体；支持的格式见 `core/media_types.dart` |
| 外挂字幕 | 仅自动匹配**同目录、同前缀**的字幕文件；命名不匹配的需手动选择 |
| iOS 模拟器 | 受 mpv 在模拟器上的限制，音频设备无法初始化，模拟器内仅能无声播放；真机不受影响 |
| 平台适配 | 视频输出依赖 media_kit/mpv，新设备可能需要针对性配置（代码中已包含 Android 黑屏与音频崩溃的规避配置） |
| 服务端部署 | openlist 挂载天翼云盘、openp2p 组网的具体配置**待补充** |
